# 调查工具

围绕稳定土地承包关系与粮食生产经营提质增效，分别从农户经营和村级治理两个视角组织调查。

| 对象 | 可编辑问卷 | 纯文本题项 |
|:---|:---:|:---:|
| 农户 | [DOCX](household.docx) | [TXT](household.txt) |
| 村干部 | [DOCX](village.docx) | [TXT](village.txt) |

DOCX 用于阅读与改编，TXT 便于检索题项。正式使用前应结合调查对象核对题意、选项与跳题逻辑；改编时记录来源和修改内容。

题项与统计口径的关系见[报告第六章及附录](../report/README.md)，复用许可见 [LICENSE](../LICENSE)。
