# 参考文献与来源

| 入口 | 用途 |
|---|---|
| [按正文引用顺序排列的书目](参考文献_按正文引用顺序.md) | 将报告中的引用编号对应到文献题录 |
| [参考文献来源登记](参考文献来源登记.csv) | 查找学术与政策来源的登记信息 |
| [项目引用格式](../CITATION.md) | 引用本项目的报告、图表与数据 |

使用时先按报告中的编号定位书目，再查 DOI、出版机构或官方来源。引用具体论断时应核对原文中的章节、页码或公式；书目登记与全文核读分别记录。
